# Sit Happens documentation

The repository root is intentionally kept small. Operational instructions and historical implementation notes live here instead of beside the application entry points.

## Operations

- `operations/BAZZITE_SETUP.md` — host setup notes.
- `operations/PRODUCTION_DEPLOY_RUNBOOK.md` — deployment procedure.
- `operations/TERMINAL_COMMANDS.md` — commonly used server commands.

## History

Historical reports and fix notes are retained for troubleshooting and audit context, but they are not current product documentation:

- `history/fix-notes/` — completed fix/phase notes.
- `history/reports/` — past stability/UI reports.
- `history/project-memory/` — archived planning/audit documents.

When current behavior conflicts with a historical note, the current source code, tests, and release checklist are authoritative.
